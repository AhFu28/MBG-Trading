## 2. File Modification & Creation Matrix

### Backend Engine (`engine/`)
| File Path | Action | Description |
| :--- | :--- | :--- |
| `engine/analyzer/smc_detector.py` | **NEW** | Algorithmic SMC: Swing Pivots, Order Blocks (OB), Fair Value Gaps (FVG) with Consequent Encroachment (50%), BOS/CHoCH, Liquidity Sweeps. |
| `engine/analyzer/bandarmology_iifs.py` | **NEW** | IDX Institutional Flow Score ($IIFS$): Net Foreign Flow Z-score ($Z_{NFF}$), Top 3 Broker accumulation ratio, Foreign Average Price tracking. |
| `engine/analyzer/event_impact_radar.py` | **NEW** | Event-Driven Catalyst Radar: 5 categories, cross-asset elasticity ($\beta$), expected return drift ($\Delta \hat{P}$). |
| `engine/analyzer/timesfm_forecaster.py` | **NEW** | Google TimesFM 2.5 zero-shot probabilistic forecasting ($q_{10}-q_{90}$) with lightweight statistical fallback. |
| `engine/paper_trading/virtual_portfolio.py` | **NEW** | Forward Paper Trading State Machine (`PENDING` $\to$ `ACTIVE` $\to$ `TP1/TP2` / `SL`), live PnL tracking. |
| `engine/paper_trading/meta_learner.py` | **NEW** | Exp3 Multi-Armed Bandit reinforcement loop: dynamic strategy weights based on realized virtual trade outcomes. |
| `engine/backtester/backtest_engine.py` | **NEW** | Event-driven backtester with intra-bar slippage (IDX fraksi harga & Binance spread) and fees ($0.15\%/0.25\%$, $0.10\%$). |
| `engine/backtester/performance_metrics.py` | **NEW** | Sharpe, Sortino, Calmar, Max Drawdown, Win Rate, Profit Factor, Expectancy ($E_R$), Deflated Sharpe Ratio. |
| `engine/database/supabase_client.py` | **MODIFY** | Add upsert/query methods for `virtual_trades`, `strategy_performance`, `smc_levels`. |
| `engine/database/schema.sql` | **MODIFY** | Database DDL for new tables. |
| `engine/run_pipeline.py` | **MODIFY** | Orchestrate all modules, execute paper trade evaluation, compute meta-weights, and output bundle. |
